# Zambia - Methodology

## Approach: Full ESCO Base Adaptation

Unlike Kenya (KESCO) and Argentina (CNO-2017), Zambia does not have a national occupational taxonomy. The approach is to adapt the Tabiya ESCO v2.0.1 base taxonomy for the Zambian labor market context.

## Pipeline (To Be Defined)

Since there is no source taxonomy to map, the standard 4-step matching pipeline does not apply. The adaptation pipeline will be defined based on project requirements.

### Potential Steps
1. Analyze Zambia's labor market structure and priority sectors
2. Review ESCO occupations for relevance to Zambia
3. Add Zambia-specific occupations not covered by ESCO (new_local)
4. Adjust skill associations for Zambian context
5. Generate Tabiya 9-file output format
